# Cursor Limits

Menu bar app and macOS widgets for your Cursor subscription usage.

Меню-бар приложение и виджеты macOS с лимитами подписки Cursor.

## Install / Установка

1. Download `CursorLimits-*-macos.zip` from [Releases](../../releases/latest).
2. Unzip and double-click **`Install.command`** (installs into **/Applications**).
3. If macOS blocks the app: right-click → **Open** → **Open**.
4. Open Cursor and sign in → menu bar icon → **Check connection**.
5. Desktop → **Edit Widgets** → search **Cursor Limits**.

From source: `./scripts/install-local.sh` (needs an Apple Development certificate for the widget gallery).

1. Скачайте `CursorLimits-*-macos.zip` из [Releases](../../releases/latest).
2. Распакуйте и дважды нажмите **`Install.command`** (ставит в **/Программы**).
3. Если macOS блокирует: ПКМ → **Открыть** → **Открыть**.
4. Откройте Cursor и войдите → иконка в меню-баре → **Проверить подключение**.
5. Рабочий стол → **Редактировать виджеты** → найдите **Cursor Limits**.

Из исходников: `./scripts/install-local.sh` (для галереи виджетов нужен сертификат Apple Development).
